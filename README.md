This repository contains the script used for the analyses of the paper "Placental DNA methylation signatures associated with infant neurodevelopment: evidence from an epigenome-wide study ". In this project, we analysed placental DNAm in 273 mother–infant pairs from the Barcelona Life Study Cohort (BiSC) to identify DNAm signatures associated to neurodevelopment at eight months, assessed with the parent reported Developmental Profile 3 (DP 3).
